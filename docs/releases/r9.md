# SM-T227U r9

For the Samsung Galaxy Tab A7 Lite LTE **SM-T227U** (`gta7lite`).
Build #47 uses Samsung Linux `4.19.191-28847731-abT227USQSCEYE2` and the
T227USQSCEYE2 vendor ABI.

## Changes since r8

- The MediaTek GED bridge automatically feeds the Android top app's
  frame completions into FPSGO on the GSI. Native XGF uses scheduler
  runtime samples from the render thread.
- Kyber drains latency samples from CPUs that go offline. ComboA eMMC
  command history defaults to off. Root can enable capture through
  `/sys/module/msdc/parameters/cmd_history` for diagnostics.
- Swapoff updates the available-device list under the swap lock. ZRAM
  swap-in retains a slot until normal swap-cache release. The reclaim
  loop now reports Tasks RCU quiescent states.
- CPUFreq initializes its policy before publishing sysfs. Also includes
  legacy OPP conversion, CMA activation, MMC device-tree reference,
  scatterlist allocation, DMA-BUF fence, video wakeup, power-supply
  event, alarm logging, and FQ-CoDel fixes.
- Retains the F2FS fixes and modular LZ4 ZRAM backend with optional
  dictionaries, CPU frequency residency, and T227U governor/PPM controls.
- Opt-in CPU bins reach 2.3 GHz on the efficiency cluster and 2.6 GHz
  on the performance cluster. The GPU starts at 680 MHz. Experimental
  GPU bins extend through 1.2 GHz, including 1.1 and 1.2 GHz on the
  parked divide-by-two clock path. These higher bins need testing
  on individual devices.
- KA 267 exposes the shared VCORE and VSRAM rails, their measured
  voltages, and the live gap. The kernel test ceilings are 900 mV
  VCORE and 1,000 mV VSRAM, with at least 75 mV of measured SRAM
  headroom required by the override. SRAM tests above 950 mV hold
  VCORE in gear 0. The rail test blocks suspend until reset.
- GPU diagnostics read both shared rails directly, including while
  the GPU is power-gated.
- Applies the stock Wi-Fi, Bluetooth, connectivity, and GPS module
  CRC compatibility map. FM broadcast reception is unsupported on
  this tablet.

## Install

1. Back up Boot in recovery. Flash `T227U-R9.zip` in recovery and reboot.
   The installer backs up and disables the vendor RamPlus fstab on
   devices that use it.
2. KernelSU Next Manager 33457 is inside the ZIP and available as a
   separate APK. Install `KernelAdiutor-T227U-ZRAM.apk` for the T227U
   CPU, GPU, and virtual memory controls. KA removes obsolete T227U
   per-core online entries from Apply on Boot.
3. Select **Plain LZ4** or place raw `.dict` files in
   `Download/KernelAdiutor` and select one in **Virtual Memory**.
   Applying the choice requires the next ZRAM initialization. The
   companion can train dictionaries on-device. The included
   `train_lz4_dictionary.py` also supports file and rooted ADB inputs.

## Verification

The full ARM64 link passed with the established configuration. The
applied vendor CRC gate verified all 203 mapped exports with zero
remaining mismatches. A separate import scan matched the vendor
Wi-Fi, Bluetooth, connectivity, GPS, and FM module imports provided
by the built-in kernel. ZIP integrity, installer identity, and both
companion APK hashes passed.

On build #44 the tablet reported 875 mV live VCORE at 962.5 mV VSRAM.
Build #47 passed the host policy, PLL and rail tests for the expanded
ranges. Boot and the new extreme bins and rail targets remain
pending device validation. The stock startup rail targets are
800 mV VCORE and 900 mV VSRAM.
